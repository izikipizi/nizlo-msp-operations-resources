Move RMM platforms without losing the estate.

Use this vendor-neutral migration workbook to reconcile endpoint identity, policies, dependencies, coexistence, rollback, validation, source removal, and evidence from discovery through closeout.

Download the CSVRead the migration guideUse the Data Package

Discover and map

Export the estate, inventory policies and dependencies, classify criticality, and map source customers, sites, groups, tags, and policies to the target.

Pilot with rollback

Choose representative noncritical endpoints, capture baselines, verify core workflows, exercise rollback, and make a documented go, revise, or stop decision.

Control coexistence

Prevent duplicate alerts, tickets, patches, scripts, and reboots while the old and new platforms overlap, then migrate through owned waves and explicit gates.

Retire with evidence

Reconcile every endpoint, retain required records, remove the source agent and credentials, close overlapping licenses, and document residual risk.

How to use it: make one copy per migration, replace blank owners and dates, link evidence instead of pasting secrets, and define rollback actions before each deployment wave.
Relationship disclosure: Nizlo, a Windows-first RMM and IT-management platform, maintains this workbook. It is designed for use with any source or target RMM and does not claim that any vendor passes its controls.
