Published formulas

Batches = ceiling(endpoints ÷ endpoints per batch)

Concurrency waves = sum of ceiling(endpoints in each batch ÷ concurrent endpoints)

Base duration = concurrency waves × (download + install + reboot + validation minutes)

Retry duration = ceiling(expected retry endpoints ÷ concurrency) × (retry + validation minutes)

Total duration = base duration + retry duration + safety reserve

This is a planning model, not a completion promise.

Real duration can change with bandwidth, update-cache behavior, patch prerequisites and supersedence, offline endpoints, disk space, restart policies, application dependencies, maintenance approvals, hypervisor load, service recovery, user deferrals, and unplanned failures.

Prove the timing on a representative pilot ring. Do not increase concurrency merely to make the model fit; verify network, update-service, infrastructure, support, and rollback capacity first. Keep a documented stop condition and a path for endpoints that miss the window.

Relationship disclosure: Nizlo maintains this vendor-neutral calculator. It does not prefill Nizlo performance figures or claim that Nizlo—or any other patching platform—will complete in the modeled time.
