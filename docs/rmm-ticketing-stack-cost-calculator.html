Published formulas

Recurring software = base + (endpoints × endpoint rate) + (technicians × technician rate) + ticketing/PSA + add-ons

Recurring labor = monthly admin/integration hours × loaded hourly rate

Complete monthly operating cost = recurring software + recurring labor

First-year total = (complete monthly operating cost × 12) + one-time implementation/migration

36-month total = (complete monthly operating cost × 36) + one-time implementation/migration

Cost is not feature or operating equivalence.

This calculator performs arithmetic only. An included ticketing module is not automatically equivalent to a complete PSA.
