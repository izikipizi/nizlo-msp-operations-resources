Start managed service with evidence, not assumptions.

An onboarding is not complete when agents install or passwords arrive. Reconcile authority, inventory, access, monitoring, patching, security, backup, service ownership, documentation, and customer acceptance before routine operations begin.

Download the CSVRead the full checklist

Authorize and scope

Name the decision owners, record included and excluded systems, define shared responsibilities, and capture maintenance or action constraints before access changes.

Discover and reconcile

Compare customer records with observed endpoints, services, vendors, risks, open work, dependencies, and critical-system ownership.

Establish controlled access

Create named least-privilege access with MFA, test every required trust path, and give shared or temporary credentials an owner and expiry.

Prove the operating model

Pilot RMM placement, alert routing, patch behavior, remote actions, audit records, backup recovery, ticket ownership, and escalation before broader rollout.

Accept with exceptions visible

Obtain named customer acceptance only after every residual risk, missing asset, failed control, and documentation gap has an owner, due date, and follow-up.

Keep secrets out of the register: link to the approved vault or system of record. Do not place passwords, recovery codes, private keys, tokens, backup contents, or regulated customer data in this CSV.
