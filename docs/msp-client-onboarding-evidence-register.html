Free MSP onboarding checklist: discovery, evidence, and go-live.

An MSP onboarding is not complete when agents install or passwords arrive. Use the 16-question discovery questionnaire to collect operating facts, reconcile 30 controls in the evidence register, and pass a six-gate go-live review before steady-state support begins.

Authorize and scope

Name the decision owners, record included and excluded systems, define shared responsibilities, and capture maintenance or action constraints before access changes.

Discover and reconcile

Compare customer records with observed endpoints, services, vendors, risks, open work, dependencies, and critical-system ownership. Use the endpoint inventory and CMDB template to keep device identity, source provenance, freshness, and exceptions explicit.

Establish controlled access

Create named least-privilege access with MFA, test every required trust path, and give shared or temporary credentials an owner and expiry.

Prove the operating model

Pilot RMM placement, alert routing, patch behavior, remote actions, audit records, backup recovery, ticket ownership, and escalation before broader rollout.

Accept with exceptions visible

Obtain named customer acceptance only after every residual risk, missing asset, failed control, and documentation gap has an owner, due date, and follow-up.

MSP client go-live checklist: six gates before steady-state support

Use these gates as a final service-readiness review, not as a substitute for the 30-control register. A gate passes only when the named owner can show current evidence and every exception has a due date and decision owner. Record both parties' acceptance in the downloadable go-live acceptance CSV.
