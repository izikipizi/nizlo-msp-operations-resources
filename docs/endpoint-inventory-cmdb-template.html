Use a stable record ID plus controlled matching signals so renames, IP changes, reassignments, and reimages do not silently split or merge records.

Record provenance

Name the source system and observation time instead of treating collected facts, assigned ownership, and service context as equally authoritative.

Describe lifecycle honestly

Separate active, temporarily offline, repair, pending retirement, retired, and disposed devices from the management state reported by an agent.

Own uncertainty

Endpoint inventory template FAQ

What fields belong in endpoint inventory?

Use durable device identifiers, owner and location, operating system, lifecycle and management states, last check-in, source and observation time, exceptions, an exception owner, and a next review date.

Can this spreadsheet feed a CMDB?

Yes—after field mapping and a non-production import test. Preserve stable record IDs and source provenance, and review duplicates before synchronization.

How often should records be reviewed?

Monitor collection freshness continuously and assign explicit review dates to stale, conflicting, or unknown records. Do not let unmanaged or unobserved endpoints remain unresolved.

Is the CSV free?

Yes. The 23-field CSV is public and ungated. Delete the clearly marked example row before use.
